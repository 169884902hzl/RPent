## 原生终态恢复

`libero_spatial_task_t1_s40` 三档均出现：回执 native_success、私有 done=True，恢复 endpoint 后 False。
原 112 个 controls 在 CPU 重放，起点/终点积分状态残差最大值都为 0。
零控制 `sim.forward()` 即可把官方 On 判据改为 False：`mjSTATE_INTEGRATION` 没有保存原 native step 的派生接触/运动学求值阶段。
新代码保存 native MjData 并原位恢复，恢复后 True，native buffers 逐字节相同。
证据：远端 `results/bounded_skills/execution_repairs_20261022/D2_three_issues/spatial_task_t1_native_buffers_CPU.json`。
`a06f3e00` 精确 CPU 面板 **764 通过**；这是 CPU 复现与修复证据，不重判旧 endpoint，也不是新 GPU 整局结果。
