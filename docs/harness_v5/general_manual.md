# 通用机器人手册

来源限于通用操作知识、原版任务和本项目训练任务。具体统计由显式原版专家轨迹补齐。RPent/PRO 材料不进入本手册。

| 形状 | 接近与抓取 | 搬运与放置 |
| --- | --- | --- |
| 开口杯、碗 | 测量把手或边沿；避开中空中心；从无障碍的一侧接近 | 保持夹持，测量物体相对夹爪的偏移，瞄准目的地中心 |
| 瓶子 | 从侧面夹持，避免细颈造成空抓；长物体减少急加速 | 留出高度和侧面间隙，逐段运动；撤离后重新确认稳定 |
| 盒子 | 从上方接近，按测量宽度调整夹持 | 对齐目标支撑面或容器内部，下降、松手、撤离 |
| 抽屉、门 | 先识别可动部件及开合方向，再执行接触动作 | 用开合前后的深度和几何变化验证；没有端点测量时不声称完全开/闭 |

失败恢复：先读失败回执，再重新感知。抓取失败换侧面、边沿或高度；放置偏离重新抓起并对准中心；伺服未到位先查障碍和位姿，不重复相同动作。静止目标在遮挡前缓存；缓存不能替代被移动物体的新测量。模型求助或提前结束不能结束未成功的回合。

大模型规则文字定义在 `robots/libero/v5_manual.py:GENERAL_RULES`；交付时用实际 Qwen tokenizer 核对不超过300 token。类别技能的成功率来自原版轨迹，缺少实测的参数明确保留为待验证。
